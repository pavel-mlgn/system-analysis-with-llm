# Прогон в Claude Code

Условия прогона Claude Opus 5.5 Max в агенте Claude Code (12.11.2026). Ответы лежат в папках кейсов под именем `answer-claude-opus-5.5-max-claude-code.md`.

Для каждого кейса отдельная папка, в ней только `code.txt` и `.claude/settings.json` из этой папки: Bash, WebSearch и WebFetch запрещены, автопамять выключена, стиль ответов Default. Выше по дереву папок нет `CLAUDE.md`, личный `~/.claude/CLAUDE.md` на время прогона убран.

Запуск, новая сессия на каждый кейс:

```bash
claude --strict-mcp-config --model claude-opus-5-5
/effort max
```

Режим разрешений auto mode, одна попытка. Сообщение агенту: `@code.txt`, затем промпт кейса без изменений, затем две технические строки, одинаковые для всех кейсов:

```
---
Технические условия этого запуска:
- файл code.txt прочитай полностью, до последней строки;
- ответ целиком, без сокращений, сохрани в файл answer.md в текущей папке.
```

Первая строка нужна, потому что в `code.txt` 2383 строки, а агент читает файлы порциями по 2000 строк. Вторая нужна, чтобы ответ не пришлось копировать из терминала. Формулировка "без сокращений" могла подтолкнуть модель к более подробному ответу: ответы в агенте на 10-35% длиннее, чем в веб-чате.
