# Задача 4. Подсчет и согласованность документов

Прочитай audit/common.md и следуй ему.

1. **Пересчет.** Для каждого кейса запусти `python3 reference/score.py review/<кейс>/final` (для 04-diagrams добавь `--mermaid review/04-diagrams/mermaid.json`) и `python3 reference/total.py review`. Сравни вывод с review/<кейс>/final/summary.md, summary.csv и review/total.md. Любое отличие - расхождение.
2. **README.** Таблица "Результаты": проценты по кейсам и итог совпадают с total.md (процент кейса = баллы / максимум кейса, округление до целого); порядок строк по итогу. Числа в тексте README (находки "N из 41", число ошибок, баллы, проценты в разделе "Добавленные модели" и "Чат и агент") совпадают с вердиктами и total.md.
3. **Статья.** В audit/article/ разделы 06-08. Все числа об основном прогоне 05.10.2026 (Claude Opus 5.5 Max и High, ChatGPT, Gemini 3.1 Pro, DeepSeek; также Argon и Kimi, если упомянуты) сверь с total.md и вердиктами. Правило колонки "Обязательное" описано в начале review/decisions.md. Сверь также итоги ошибок по типам и общие числа (например, сколько всего ошибок сделали модели основного прогона).
4. **Диаграммы.** review/04-diagrams/mermaid.json совпадает с таблицей в mermaid-report.md; число неоткрывшихся диаграмм учтено в баллах.
5. **Обезличивание.** review/_mapping.json: каждая буква указывает на существующий файл ответа, файлы в anon/ совпадают с исходными (с учетом markers_removed), одна модель - одна буква в кейсе.
