# Контрольная сверка

17.11.2026 эксперимент проверила модель Claude Fable 5.2 в Claude Code (`/effort max`), в одноразовом клоне репозитория, без интернета и без права менять файлы. Итоги и выводы - в разделе "Контрольная сверка" основного README.

| Файл | Что это |
|---|---|
| `common.md` | общие правила сверки и формат отчета |
| `task-1-etalon.md`, `report-1.md` | задание и отчет: эталон и чек-листы |
| `task-2-decisions.md`, `report-2.md` | задание и отчет: ручные решения и итоговые вердикты |
| `task-4-consistency.md`, `report-4.md` | задание и отчет: подсчет и согласованность README, `total.md` и статьи |
| `blind/<кейс>-<буква>/verdict.json` | слепая перепроверка 12 пар "ответ + кейс" |
| `blind/message-template.txt` | сообщение для слепой проверки (пример для пары 02-I) |
| `blind/compare.md` | сравнение слепых вердиктов с итоговыми |

Задача 3 - это слепая перепроверка. Каждая пара проверялась в отдельной сессии, в папке были только задача, обезличенный ответ, эталон, код и промпт верификатора, Bash и интернет запрещены.

Отчеты сохранены без правок. Вспомогательные скрипты, на которые они ссылаются (`audit/t1_*.py`, `t2_*.py`, `t4_*.py`), модель писала для себя по ходу сверки, в репозиторий они не включены. Номера строк в отчетах относятся к состоянию репозитория на коммите f028d99.

Баллы по итогам сверки не менялись. Решения, по которым отчеты предлагают другие оценки, и их влияние на итог перечислены в отчетах 1 и 2.
